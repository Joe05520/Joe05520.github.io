# Usage Sentinel legacy Pages compatibility

This static site preserves the former `/usage-sentinel/` website and update-channel URLs after the main repository was renamed to **ai-agent-usage-limit-reset-forecast**.

The website pages link to the new site. The legacy update channel keeps a signed migration manifest whose GitHub URLs use the old repository alias (GitHub redirects those URLs). The update uses the same existing Ed25519 public key. No credentials, analytics backend or account data are hosted here.

The bridge will be frozen at migration release 1.8.1: install that version to use the new update endpoint for later releases. Preview builds remain opt-in.

Main project: https://github.com/Joe05520/ai-agent-usage-limit-reset-forecast
